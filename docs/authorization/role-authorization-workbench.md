# 页面功能角色授权：实施与运维指南

## 面向实施人员的操作闭环

角色授权只使用业务语言，不要求理解接口、资源编码或动作编码。

1. 打开“角色管理”，选择角色并进入“角色授权”。
2. 按页面选择“允许进入页面”“允许查看”和“允许操作”。三者含义不同：进入页面只控制入口；查看决定能读取内容；新增、编辑、删除、导出等必须单独授权。
3. 系统自动补齐必需功能并标记“系统自动添加”。如果某项仍被其他操作依赖，必须先取消依赖它的操作。
4. 对支持数据范围的查看功能设置页面默认范围。操作默认跟随页面范围，也可单独缩小。选择“指定组织”时必须选择组织。
5. 字段保护和业务限制仅在业务服务已经声明并通过执行验证时显示；前端控件隐藏不构成安全保护。
6. 保存草稿。草稿不影响线上用户。
7. 使用“当前线上角色”或从用户选择器选择“实际用户”验证结果，无需手工填写用户 ID。结果用业务语言解释是否允许、数据范围、字段规则和业务限制。
8. 点击“校验权限”。系统会检查目录版本、依赖、后台执行能力、数据范围、字段保护、业务限制、操作者权限和权限差异。
9. 查看业务摘要并“确认发布”。只有发布成功后才影响持有该角色的用户。
10. 发布失败时旧版本保持有效；发布历史可恢复任一不可变版本。

## 产品与业务服务开发人员

页面功能清单由页面 Owner 维护，系统管理首批清单位于 `SystemPageCapabilityManifestConfig`。每个功能必须声明：

- 页面和业务名称；
- `ACCESS`、`READ` 或 `OPERATION` 分类；
- 必需功能依赖；
- 一个或多个受治理的运行时权限目标；
- 是否支持数据范围和字段限制；
- 需要的业务守卫及 Owner 执行能力。

清单同步按“目录编码 + 版本”幂等。同一版本内容变化会被拒绝；新目录激活不会自动重编译角色。依赖环、跨租户引用、失效目标和未验证执行能力会使功能不可发布。

## 平台管理员诊断

“企业授权 → 页面功能映射诊断”显示技术证据，包括资源、动作、Owner、依赖和就绪状态。普通角色实施工作台不会显示这些代码。

状态含义：

- `READY`：可配置和发布；
- `PARTIAL`：可选连接不完整，需要平台复核；
- `BROKEN`：必需后台能力或执行保护缺失，禁止发布；
- `UNMAPPED`：尚未连接运行时权限，禁止发布。

激活新目录后，系统比较当前发布证据并生成漂移记录、受影响角色和用户数。漂移不会自动改变线上权限。

## 旧权限迁移

租户管理模式为：

- `LEGACY`：旧授权可写，新工作台可准备草稿但不能发布；
- `MIGRATION`：允许迁移分析、复核草稿和页面功能发布；
- `PAGE_CAPABILITY`：只允许页面功能工作台写角色授权，旧功能授权写入被拒绝。

迁移分析将旧授权分为 `EXACT`、`PARTIAL`、`AMBIGUOUS` 和 `UNMAPPED`。只有能完整反推的 `EXACT` 项自动进入复核草稿；其他项必须人工处理。若编译结果包含旧授权没有的权限，草稿会标记为可能扩大权限，实施人员必须逐项复核并明确确认，系统不会静默发布。

切换顺序：先部署数据库和后端，再同步并激活目录；在 `MIGRATION` 模式迁移和验证全部角色；确认没有非预期权限扩张后切换到 `PAGE_CAPABILITY`。切换后不得继续使用旧入口写角色授权。

## 发布、回滚和审计

校验令牌绑定租户、角色、草稿版本、目录版本、操作者、操作者权限版本、编译差异和有效期。任何一项变化都必须重新校验。

发布在单一数据库事务中创建不可变发布快照、运行时授权、数据策略、字段策略、守卫证据和活动版本指针。任何写入失败都会回滚，原活动版本继续生效。回滚直接重放历史编译快照，不按当前映射重新解释，也不修改历史证据。

审计记录草稿创建和变更、自动依赖、校验、发布、回滚、漂移与迁移分析，同时记录操作者、TraceId、受影响用户数、业务摘要和已脱敏技术证据。令牌、密码和密钥不会写入审计证据。

## 事故处理

- 用户看不到菜单：确认租户模式；在 `PAGE_CAPABILITY` 模式必须存在活动发布及对应 `GRANT` 证据，缺失时按 fail-closed 隐藏。
- 按钮可见但接口拒绝：以前端只是提示为前提，检查 Owner 服务的运行时决定、数据范围、字段规则和守卫结果。
- 校验过期或提示权限已变化：重新保存草稿并校验，不要绕过令牌。
- 新目录产生漂移：查看受影响角色和用户，不要直接重编译；创建新草稿、验证后发布。
- 发布失败：保留当前活动版本，使用 TraceId 查询发布失败日志和审计；修复后从草稿重试。
- 权限误配：从发布历史恢复最近正确版本，并对误配版本和受影响用户执行审计复盘。
- 决策服务或证据不可用：菜单、页面、操作和直接 API 均应拒绝，不得回退到“默认允许”。
